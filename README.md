
#  e-EidCard: A Digital Touch to Tradition

**e-EidCard** is a full-stack interactive web application that reimagines the nostalgic experience of sending handmade Eid cards for the digital age. Launched for the Eid season, it allows users to design, customize, and share 3D-animated greetings that feel personal and tactile.

## Technology Stack
This project was built using a modern, scalable stack to ensure high performance and smooth user interactions:

*   **Framework:** [Next.js](https://nextjs.org/) (App Router & TypeScript) 
*   **Database:** [Supabase](https://supabase.com/) (PostgreSQL) for real-time data persistence.
*   **Animations:** [Framer Motion](https://www.framer.com/motion/) for realistic 3D card physics.
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) for a responsive UI.
*   **Icons:** [Lucide-React](https://lucide.dev/)
*   **Deployment:** [Netlify](https://www.netlify.com/)

---

##  Features
*   **Interactive 3D Animation:** A realistic card-opening gesture that mimics physical paper cards.
*   **Real-Time Customization:** 
    *   **15+ Themed Covers:** Minimalist, traditional, and playful designs.
    *   **Preset Wishes:** A library of 8+ thoughtful messages in English and Urdu.
*   **Dynamic URL Generation:** Each card is stored with a unique ID, creating a shareable link instantly.
*   **Social Optimization:** Optimized for seamless sharing via WhatsApp and LinkedIn.
*   **User Feedback:** Integrated "Copy Link" and "Success" states for a better UX.

---

##  Technical Highlights
*   **WYSIWYG Preview:** Implemented complex state management to ensure the preview card updates instantly as the user types.
*   **Conditional Asset Loading:** Developed a custom logic handler to manage mixed file formats (JPEG/PNG) across 15+ themes without broken links.
*   **Scalability:** Successfully handled **135+ unique entries** within the first 24 hours of launch, demonstrating the app's ability to handle seasonal traffic spikes.
